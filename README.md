# Vurata

Website for Vurata, a concierge service for villa guests in Bali: private tours, in-villa wellness and personalized concierge services. Live at https://vurata.com

## About

A single-page static site (plain HTML, CSS and JavaScript, no build step). Guests browse the experiences and get in touch to arrange them.

- `index.html` is the whole site.
- `images/` holds the photography and `branding/` the logos and brand assets.
- `CNAME` sets the custom domain.
